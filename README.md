# Visionários

Plataforma educacional desenvolvida para reunir recursos de apoio aos estudos e facilitar a organização de atividades acadêmicas, com áreas para alunos, professores e suporte administrativo.

## Funcionalidades

- Cadastro e login de usuários.
- Área do aluno com materiais de estudo e livros digitais.
- Cadastro, edição e exclusão de atividades pelos professores.
- Calendário para acompanhamento das atividades.
- Painel administrativo para gerenciamento de funcionários.
- Informações sobre vestibulares, provas, gabaritos e bolsas universitárias.

## Tecnologias

- **PHP** para processamento das operações e autenticação por sessões.
- **MySQL e PDO** para armazenamento e acesso aos dados.
- **HTML, CSS e Tailwind CSS** para estrutura e apresentação das páginas.
- **JavaScript** para interações, calendário e envio de formulários.
- **Font Awesome** para os ícones da interface.

## Objetivo

Centralizar informações e ferramentas educacionais em um único ambiente, apoiando a rotina de estudos dos alunos e o gerenciamento de atividades pelos professores.
